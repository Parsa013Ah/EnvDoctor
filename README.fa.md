# 🩺 envdoctor

**چک‌آپ فایل `.env` پروژه‌ت، توی یک ثانیه.**

```bash
npx envdoctor
```

بدون نصب، بدون تنظیمات. کدت، `.env` و `.env.example` رو می‌خونه و بهت می‌گه:

- متغیری که توی کد استفاده شده ولی توی `.env` نیست
- `.env` که توی `.gitignore` نیست (خطر لو رفتن کلیدها)
- کلید واقعی که اشتباهی توی `.env.example` گذاشتی (AWS، گیت‌هاب، تلگرام و...)
- متغیرهایی که تعریف شدن ولی هیچ‌جا استفاده نمی‌شن

```bash
npx envdoctor --fix   # .env.example رو خودکار از روی کد می‌سازه یا آپدیت می‌کنه
npx envdoctor --strict  # برای CI: با هشدار هم fail می‌شه
```

صفر وابستگی، Node 18+، پشتیبانی از JS/TS، Python، Go، Ruby، PHP، Java، Rust و C#.
